# Issue #192 — original word-level `norm.lang` source attribute

## Research
The immutable pinned TT source census `CopticScriptorium/corpora@3ac067f1709a0012daf39ea8da2fac79980176a5` in [PR #186 / job 39453660227](https://github.com/alexsosn/CopticScriptorium-TF/actions/runs/39453660227) counts **57,369 source `norm.lang` attrs** among **2,394,354 original norm openings** across 2,628 physical source records including ZIP members. Current `parser.py` word-opening code retains `norm`, POS, lemma, head and source text, but does not copy the word's own `lang` attr; `Word`, `GraphSlot` and `writer._SCALAR_FEATURES` have no exact original word language field. Separate nested `<lang>` source node and `<morph lang>` annotations are not substitutes and cannot be conflated with this literal TT attribute. Corpus scientific semantics of the original language label are not inferred by the converter.
