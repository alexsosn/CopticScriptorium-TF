## Scoped implementation decision
Introduce **read-only**, strictly hashed external diagnostic. It accepts observed source `DocumentModel` + *existing* Coptic→LXX candidate refs; it never modifies the resolver or TF module. Only the known source-byte-locked Bohairic Zechariah witness can be called an `agreement`/`disagreement` with the English→LXX table. For any other Coptic source, a TVTMS changed verse is `source_scheme_unverified`, not a contradiction. A missing TVTMS row is `no_explicit_exception`, not verified identity. Null/partial rows and unsupported OT books stay visible. Reports aggregate statuses by source family/CTS edition/Greek book with bounded IDs, never the texts or all per-verse matches.
